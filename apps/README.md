# Apps Directory

This directory contains all application-level services and components as defined in MASTER.md v2.2 (Section 18).

## Structure
- `api/` - FastAPI / API layer
- `orchestrator/` - LangGraph orchestration
- `alert_gateway/` - Alert reception and normalization
- `context_service/` - Operational context building
- `rag_service/` - Knowledge RAG service
- `memory_service/` - Operational memory service
- `execution_service/` - Action execution service
- `verification_service/` - Independent verification service
- `decision_engine/` - Policy-based decision engine
- `approval_service/` - Human approval workflow
